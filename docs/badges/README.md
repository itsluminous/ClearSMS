## get-it-on-obtainium.png

From [Obtainium](https://github.com/ImranR98/Obtainium)
(`assets/graphics/badge_obtainium.png`, GPL-3.0). Vendored rather than

hotlink `raw.githubusercontent.com` for this, and a badge that 404s is
worse than no badge.
